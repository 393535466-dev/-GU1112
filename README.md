# 懒人选股

独立运行的 A 股选股工具。选择持仓方向后，程序筛出最多 5 只符合条件的股票，并逐只给出筛选评分、入选理由、主要风险、预计持仓区间和重新评估条件。

| 方向 | 筛选重点 | 持仓参考 |
| --- | --- | --- |
| 短线动量 | 成交活跃、量价动量 | 1–5 个交易日 |
| 趋势波段 | 趋势、估值和流动性 | 5–20 个交易日 |
| 低波稳健 | 较低波动、较浅回撤 | 10–30 个交易日 |
| 长线观察 | 估值、流动性和稳定性 | 3–6 个月 |

持仓时间由策略方向给出。筛选评分在同一方向内用于排序，评分包含风险调整。符合条件的股票不足 3 只时会如实显示。

候选名单分别显示行情交易日和获取时间，并列出每只股票的行情价与当日涨跌幅。行情源返回的交易日期须与当前应有交易日一致，过期或日期无法核验的数据会继续尝试备用来源。候选日线也须通过日期和质量校验。打开旧结果或重新回到页面时会检查有效期，跨交易日、收盘前旧结果和超过五分钟的盘中结果会自动重新筛选。短线动量沿用当日涨幅 1%–9.5% 的条件。

选股行情优先使用腾讯财经逐股报价中的日期和时间，批量获取价格、成交额、量比、估值等字段。东方财富数据中心或新浪仅提供股票代码目录，不把目录中的旧价格或获取时间冒充当前行情。报价与目标日期的覆盖率须达到目录的 90%，缺失批次、旧日期和无日期报价不得用于凑足候选。东方财富数据中心作为备用行情源时仍须通过日期校验；其日更数据尚未更新时不会被当成盘中行情。

「大盘分析与趋势」汇总最近一个已收盘交易日的上证指数、深证成指、创业板指和沪深 300，展示盘面强弱、涨跌家数、样本成交额和行业板块涨跌。盘面强弱沿用原项目的 45% 上涨家数占比、35% 指数表现、20% 涨跌停对比。指数趋势按收盘价与 20 日、60 日均线的相对位置判断，图表显示最近最多 60 个交易日。指数日线由新浪财经和腾讯行情提供，涨跌停采用东方财富统计。缺失项目按实际覆盖标明，页面可手动更新同一交易日的数据。

「板块分析」分行业和概念两张榜单，支持按涨幅、跌幅或成交额排列，也可按板块名称查找。点开板块可看同类涨幅名次、与中位数的差距、成交额和领涨股；来源提供明细时，还会展示成分股涨跌分布。最近一次同日板块快照保存在本地，成交额和成分股缺失时按实际覆盖展示。

## 本机启动

使用 Python 3.12。进入这个项目目录后运行以下命令。

```bash
uv venv --python 3.12
uv pip install -r requirements.txt
.venv/bin/python -m uvicorn lazy_picker.app:app --host 127.0.0.1 --port 8011
```

打开 [懒人选股](http://127.0.0.1:8011/)。停止时在启动终端按 Ctrl+C。服务以单进程在本机运行，筛选历史和行情缓存保存在项目的 `data/` 目录。

规则筛选无需模型密钥。要启用本机 DeepSeek 自由问答和建议解读，将 `.env.example` 复制为 `.env`，填入本项目的 `DEEPSEEK_API_KEY` 后重启服务。提问时发送问题、产品规则、当前候选及缓存里的收盘摘要给 DeepSeek。模型超时或返回不完整时使用规则内容。[DeepSeek API 文档](https://api-docs.deepseek.com/api/create-chat-completion/)

在候选名单旁点「AI 建议」，或在股票卡片点「查看建议」直达对应股票。建议包含一句话结论、空仓与持仓各自的观察条件、风险、预计持仓区间和复查条件。技术参考使用同一来源的已收盘日线计算 MA5、MA10、MA20 与乖离率，数据不足时隐藏价位。DeepSeek 根据这些数据整理一句话解读，价位和观察条件由程序计算。新闻、公告、筹码及主力资金暂未接入。弹层的「问答」可以继续问评分、入选理由或风险。

## Vercel 部署状态

仓库根目录的 `pyproject.toml` 声明 Python 3.12、运行依赖和 `lazy_picker.app:app` 入口。Vercel 的 Root Directory 应选择包含此文件、`requirements.txt` 和 `lazy_picker/` 的目录；本 Git 仓库对应根目录 `.`，框架选择 FastAPI。`vercel.json` 配置香港区域和 300 秒执行上限。

连接一个 **private** Vercel Blob 存储到此项目，让 Vercel 自动配置存储凭据。无需将凭据写入仓库。云端筛选历史和按日期保存的收盘摘要使用私有 Blob，临时行情缓存使用 `/tmp/lazy-stock-picker`。最新结果从不可变记录中选择，避免覆盖固定文件后读到旧缓存。应用启动不再创建 SQLite，也不再清理其他实例的任务。

云端筛选在一次请求内完成，保存结果后才返回，请在筛选期间保持页面打开。它不依赖响应结束后继续运行的线程。超出平台的 300 秒上限会返回超时，页面提示重新尝试。需要长于此限制的任务时，应进一步拆分为持久队列任务。最新结果和历史查询从私有存储读取，实例重启后仍保留。

部署域名从 Vercel 的系统变量加入允许名单；绑定额外域名时，在环境变量 `LAZY_PICKER_ALLOWED_HOSTS` 中以逗号分隔填写。`DEEPSEEK_API_KEY` 可在 Vercel 项目中单独配置；未配置时页面使用规则建议。

验收需覆盖 `/api/health`、三个页面、筛选请求、跨请求读取历史、大盘与板块的实际交易日期，不能仅凭构建状态判断功能可用。本机服务仍使用原有 SQLite 和后台筛选方式。

官方参考：[FastAPI 入口配置](https://vercel.com/kb/guide/ship-a-fastapi-app-on-vercel)、[Functions 文件存储限制](https://vercel.com/docs/functions/runtimes#file-system-support)。

## 手机 H5 与 GitHub Pages

手机用「选股 / 大盘 / 板块」底部导航，桌面用顶部导航。主题默认跟随系统，右上角可以切换并记住亮暗偏好。板块详情在手机从底部展开，在桌面和榜单并排显示。

GitHub Pages 从 `gh-pages` 分支的根目录托管 H5。托管版展示标有交易日期的收盘快照：可切换选股方向和指数，可查询与排序板块；成分股明细仅收录当期有数据的领先板块。本机服务负责新的筛选、更新行情及查询其余成分股。

托管版显示当期收盘快照里已生成的建议和 DeepSeek 解读，并在浏览器内回答常见规则问题。DeepSeek 自由问答需要运行本机服务。

更新托管版前，启动本机服务，在收盘后完成各方向的筛选并确认大盘和板块的交易日期一致，然后运行：

```bash
.venv/bin/python scripts/export_pages.py
```

将 `dist/` 里的产物更新到 `gh-pages`。导出包含三页和数据快照，筛选运行记录、行情缓存、环境文件与密钥留在本机。主图 `lazy_picker/web/hero-orb.png` 由内置 ImageGen 生成，提示为透明背景的蓝紫缎面玻璃折带球体。

## 实现

页面调用同源 FastAPI 接口，后台任务从新浪、东方财富等来源获取行情快照，依次执行硬条件筛选、候选日线计算、因子评分和风险调整。任务状态和结果写入 SQLite。行情源失败时可复用近期成功的快照，页面标出缓存和行情快照时间。

选股原语和四份策略模板来自 `daily_stock_analysis` 的固定版本，随本项目交付。许可与来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
